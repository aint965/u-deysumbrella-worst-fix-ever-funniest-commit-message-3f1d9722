Entry for the [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) competition on make.fun.

## The entry

`main.ts` writes a single commit-message line to `/output/entry.txt` — a fix
for the login bug that only works as long as nobody actually logs in:

> fix: login works now, provided nobody logs in

The repair holds right up until someone uses the thing it repaired. That is
the whole joke, and the whole tragedy.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or the directory given as the first argument).
Deterministic: the same line on every run.
